# Python Mini Game Project 🎮

This is a beginner-friendly Python mini game project that allows users to play two simple games through a menu-driven program:

1. **Stone – Paper – Scissors**
2. **Dice Roll Game**

The program uses Python functions for game logic and the `random` module to generate computer choices and dice results.

## Features
- Menu-based interface
- Uses functions for modular code
- Random result generation
- Winner/result shown after every round
- Beginner-friendly Python project

## Technologies Used
- Python
- Random Module

## How to Run
1. Clone the repository
2. Run the Python file:
```bash
python game.py
